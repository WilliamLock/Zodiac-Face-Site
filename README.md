# Zodiac Face product site

Public static product, gallery, privacy, support and release pages. Source code for the iOS app is maintained separately in a private repository.

Intended URL: https://williamlock.github.io/Zodiac-Face-Site/

No analytics, cookies, external image embeds or JavaScript dependencies are added. All displayed images are approved icon or retained screenshot exports, with hashes in asset-provenance.json. Generated portraits are labeled as promotional artwork.
